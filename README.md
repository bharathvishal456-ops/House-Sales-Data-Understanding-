# House Sales Data Understanding, Cleaning & Feature Engineering

## Project Overview
This project focuses on understanding, cleaning, and transforming house sales data using Python.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Project Tasks
- Data understanding and exploration
- Handling missing values
- Removing duplicate records
- Feature engineering
- House price analysis
- Data visualization

## Dataset Features
- House area
- Bedrooms and bathrooms
- Year built
- Neighborhood
- Annual property tax
- Sale price

## How to Run
1. Install the required libraries:
   `pip install pandas matplotlib`
2. Keep the CSV dataset and Python script in the same folder.
3. Run the Python script:
   `python house_sales_analysis.py`

## Output
A cleaned dataset named `cleaned_house_sales_data.csv` and visualizations of house prices.

## Note
The included dataset is sample data created for educational purposes.
